# Ansprechpartner finden

Von Leadscraper, leadscraper.de. Frei nutzbar und anpassbar.

Du findest für eine Firma die Person, die über das Angebot des Nutzers entscheidet. Ein Anschreiben an die richtige
Person wird gelesen. Eines an die falsche wird weitergeleitet oder gelöscht.

## Was du brauchst

1. Name und Internetadresse der Firma.
2. Ein Satz vom Nutzer: Was bieten Sie an?
3. Wenn vorhanden: Funktionen, die bei bisherigen Kunden entschieden haben.

## Ablauf

1. **Funktion bestimmen.** Wer entscheidet in einer Firma dieser Größe über so ein Angebot? Bis etwa 50 Mitarbeiter
   ist das meist die Geschäftsführung. Darüber gibt es oft eine Leitung für den Bereich: Einkauf, Technik, Vertrieb,
   Personal. Schreib eine erste und eine zweite Wahl auf.
2. **Quellen der Firma lesen.** Impressum, Team- oder Kontaktseite, Pressemeldungen, Stellenanzeigen (dort steht
   oft, an wen die Stelle berichtet), Vorträge und Fachartikel mit Namen.
3. **Öffentliche Register.** Die Geschäftsführung steht im Impressum und im Handelsregister.
4. **Abgleichen.** Steht die Person in einer Quelle, die älter als ein Jahr ist, suche eine neuere Bestätigung.
   Leitungen wechseln.
5. **Erreichbarkeit.** Notiere die Adresse oder Telefonnummer nur, wenn sie öffentlich bei der Firma steht.

## Regeln

- Erfinde nichts. Kein Name ohne öffentliche Quelle der Firma oder eines Registers.
- Keine E-Mail-Adresse raten. Ein vermutetes Muster wie „vorname.nachname@“ heißt im Ergebnis „Vermutung, nicht
  bestätigt“ und wird vor dem Versand geprüft.
- Nichts aus privaten Profilen, nichts über Familie, Wohnort oder Hobbys.
- Findest du niemanden, ist das Ergebnis die Funktion ohne Namen. Das ist besser als ein falscher Name.
- Ob der Nutzer die Person anschreiben darf, klärt dieser Skill nicht.

## Ergebnis

```
Firma:
Erste Wahl:      Funktion, Name (Quelle, Datum)
Zweite Wahl:     Funktion, Name (Quelle, Datum)
Erreichbar über: öffentliche Adresse oder Telefon, mit Quelle, sonst „nicht öffentlich“
Unsicher:        was noch geprüft werden muss
```
